# DIY Travel App — Starter Build

## What this first build includes
- Responsive desktop + mobile shell
- Trip dates and destination
- Arrival and departure details
- Hotel check-in/check-out
- Manual places list with opening/closing time, duration, and priority
- Live day itinerary with Done / Skip state
- Trip budget and shopping budget
- Things-to-buy list with planned price, quantity, actual price, and priority
- Things-to-bring checklist
- Things-to-buy checklist linked to the Budget page
- LocalStorage persistence

## Run it
1. Open a terminal in this folder.
2. Run: npm install
3. Run: npm run dev
4. Open the localhost URL Vite prints in the terminal.
